# Visualizador de música

Versión estable con: 4 animaciones (Espectro, Ondas, Partículas, Planetas) y 3 fondos (Aurora, Ondulado, Prismas).

- Preview: máximo 90 segundos o la duración completa si el audio es más corto.
- Exportación: canción completa, sin límite artificial de 90 segundos.
- Randomizador: genera únicamente combinaciones de opciones existentes y posiciones seguras.
- Prismas: fondo geométrico multicolor, ligero.
- Planetas: órbitas ligeras con planetas de distintos tamaños, estrellas y estrella fugaz ocasional.
