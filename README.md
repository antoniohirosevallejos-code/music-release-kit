# MP3 to WEBM — Video Visualizer V1

V1 desktop, sin servidor: MP3/WAV → título + artista → preset visual → preview de 10/20 s → WEBM 1920×1080.

El formato oficial es WEBM porque GitHub Pages + MediaRecorder no puede garantizar MP4. La portada se genera dentro del diseño, así se controla la resolución y el encuadre.

Objetivo: Chrome/Edge de escritorio.
